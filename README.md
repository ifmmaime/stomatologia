# Стоматологическая клиника «Доктор Гудман» с ИИ-ассистентом

Этот проект представляет собой современный веб-сайт стоматологической клиники со встроенным интерактивным виджетом ИИ-консультанта. Виджет работает локально на базе большой языковой модели (LLM) через платформу **Ollama**.

---

## 🚀 Инструкция по запуску

### Шаг 1. Запуск Ollama на вашем ноутбуке
1. Скачайте и установите **Ollama** с официального сайта: [https://ollama.com](https://ollama.com).
2. Запустите Ollama в вашей системе.
3. Откройте терминал/командную строку и скачайте необходимую модель (по умолчанию используется `granite4.1:3b`):
   ```bash
   ollama run granite4.1:3b
   ```
   *(Убедитесь, что загрузка завершилась успешно и Ollama отвечает в консоли).*

### Шаг 2. Настройка бэкенда
1. Перейдите в папку `backend/`.
2. В этой папке уже создан файл конфигурации `.env`. Если Ollama запущена на том же ноутбуке, параметры по умолчанию изменять не требуется:
   ```env
   PORT=3000
   OLLAMA_URL=http://localhost:11434/api/generate
   OLLAMA_MODEL=granite4.1:3b
   ```
   *Примечание: Если Ollama развернута на другом устройстве в сети, измените `localhost` в `OLLAMA_URL` на локальный IP-адрес этого устройства (например, `http://192.168.1.6:11434/api/generate`).*

3. Установите зависимости бэкенда. Откройте терминал в папке `backend/` и выполните:
   ```bash
   npm install
   ```

### Шаг 3. Запуск веб-сервера
Запустите бэкенд из папки `backend/`:
- **Обычный запуск:**
  ```bash
  npm start
  ```
- **Запуск в режиме разработки** (с автоматическим перезапуском при изменениях в коде):
  ```bash
  npm run dev
  ```

После успешного запуска в терминале отобразится:
```text
=================================================
  СЕРВЕР СТОМАТОЛОГИИ УСПЕШНО ЗАПУЩЕН!
  Сайт клиники: http://localhost:3000
  API чата:     http://localhost:3000/chat
=================================================
```

### Шаг 4. Открытие сайта в браузере
Перейдите по адресу:
👉 **[http://localhost:3000](http://localhost:3000)**

*Сервер автоматически раздает сайт из папки `frontend/` и подключает ИИ-виджет к бэкенду.*

## 🛠️ Что было исправлено и улучшено

1. **Ресурсы сайта (`saitik.html`):**
   - Исправлены битые ссылки на стили, скрипты и картинки. Все обращения перенаправлены на существующую папку `./assets/` вместо отсутствующей `./saitik_files/`. Теперь сайт загружается быстро и полностью со всеми исходными анимациями и сетками.

2. **Очистка и модульность бэкенда:**
   - **`server.js`:** Полностью очищен от дублирования логики работы с Ollama. Теперь он выполняет только инициализацию Express, CORS, раздачу статических файлов и подключение маршрутов.
   - **`services/context.js`:** Добавлен сервис для отказоустойчивой загрузки текстовой базы знаний (`rules.txt`, `clinic-info.txt`, `faq-client.txt`). Пути к файлам вычисляются динамически относительно корня проекта, предотвращая ошибки запуска.
   - **`services/ollama.js`:** Избавлен от ReferenceError багов (в которых использовались необъявленные переменные) и переведен на гибкие настройки из `.env`.
   - **`routes/chat.js`:** Добавлена валидация входящих запросов и форматированный вывод сообщений об ошибках клиенту.

3. **Интерактивный ИИ-виджет (UI/UX):**
   - Переработан дизайн виджета в соответствии с современными стандартами премиального веб-дизайна (Montserrat, плавные градиенты, тени).

   - Добавлены плавные анимации появления сообщений.
   - Добавлен **индикатор печати** (анимированные троеточия) во время генерации ответа моделью.
   - Адаптивный мобильный режим: на экранах смартфонов виджет разворачивается на весь экран для максимального удобства.
